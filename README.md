# Пульс — расписание медколледжа

Удобное расписание Псковского медицинского колледжа: пары своей группы в один тап, можно поставить на телефон как приложение.

- `index.html` — сайт (PWA)
- `data.json` — расписание всех групп
- `scripts/update.py` — робот: скачивает таблицу колледжа, разбирает и обновляет `data.json`
- `.github/workflows/update.yml` — запускает робота каждый час

Ручной запуск: вкладка **Actions** → «Обновить расписание» → **Run workflow**.
